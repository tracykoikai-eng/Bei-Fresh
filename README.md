# BeiFresh

BeiFresh is a secondhand marketplace platform where buyers and sellers can
connect and trade used products easily.

## Target Users

- Buyers
- Sellers
- Students
- General users
- Administrators

## Main Features

### Buyers
- Create an account and log in
- Search for products
- Filter products by price
- Filter by category
- Filter by location
- View product details
- Contact sellers
- Save/favorite products

### Sellers
- Create a seller account
- Add products
- Upload product images
- Set product prices
- Add product descriptions
- Edit or remove listings
- Manage their products

### Admin
- Admin login
- Manage users
- Manage products
- Manage categories
- Review reported listings
- View marketplace activity
